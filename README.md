# Application de vente de formations

Application Java permettant de consulter et d'acheter des formations.

## Installation

Le projet utilise Husky et Commitlint pour vérifier les messages de commit.

Pour installer les dépendances :

npm install

## Structure du projet

- `database/` : contient le script SQL permettant de créer la base de données.
- `docs/` : contient les diagrammes UML, les spécifications fonctionnelles, le MCD et la JavaDoc.
- `ventes_formations/` : contient le code source de l'application Java.

## Documentation

Le dossier `docs` contient :

- les diagrammes UML (cas d'utilisation, classes et séquence) ;
- les spécifications fonctionnelles ;
- le MCD réalisé avec Looping ;
- la JavaDoc.

La JavaDoc est également disponible en ligne :
